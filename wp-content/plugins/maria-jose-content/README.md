# María José Content

A WordPress plugin that manages artist content independently from the active theme.

## Content types

- `mj_video`: music videos, live sessions, and related YouTube metadata.
- `mj_show`: upcoming performances, dates, and locations.

## Requirements

- WordPress 6.4 or newer.
- PHP 8.0 or newer.

## Installation

1. Copy the `maria-jose-content` directory into `wp-content/plugins`.
2. Activate **María José Content** from the WordPress Plugins screen.
3. Manage entries from the **Videos** and **Agenda** admin menus.

The plugin keeps the existing `mj_video` and `mj_show` identifiers, so content remains available when the active theme changes.
